# Student Performance Predictor

## Project Overview

Student Performance Predictor is a machine learning project that predicts a student's final marks based on their study hours, attendance, and previous marks.

The project uses Linear Regression to learn the relationship between these factors and final academic performance.

## Features Used

- Study Hours
- Attendance
- Previous Marks

## Target Variable

- Final Marks

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Machine Learning Model

Linear Regression was used to train the prediction model.

The dataset was divided into:
- 80% training data
- 20% testing data

## Model Performance

The model achieved the following results:

- Mean Absolute Error (MAE): 0.254
- Mean Squared Error (MSE): 0.098
- R² Score: 0.9984

The high R² score indicates that the model performed very well on the test data.

## Example Prediction

For a student with:

- Study Hours: 6
- Attendance: 85%
- Previous Marks: 70

The model predicted approximately:

**73.31 Final Marks**
